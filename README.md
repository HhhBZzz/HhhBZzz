## 🦾 My Project — [SpringClaw](https://github.com/HhhBZzz/SpringClaw)

**The Agent Runtime Where Every Thought Is Visible**

- 🔀 **7 paradigms** switchable at runtime (ReAct · Plan-Execute · Multi-Agent · Reflexion · …)
- 🎨 **Blueprint Canvas** — watch a light-shuttle race through the agent's execution path, click any node to X-Ray the actual code
- 🏗️ **Harness Conveyor** — 10 layers of product shells unpacked as a visual assembly line
- 🚀 **Deployed** — Vercel + Cloudflare Tunnel, ~$5/mo

**[🚀 Live Demo](https://spring-claw.vercel.app)** · **[📖 GitHub](https://github.com/HhhBZzz/SpringClaw)**
